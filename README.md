# Exercism – C# Track

Este repositorio contiene mis soluciones a los ejercicios del **track de C#** en [Exercism](https://exercism.org/).

El objetivo de este repositorio es practicar y afianzar conceptos fundamentales y avanzados del lenguaje **C#**, buenas prácticas, y el uso de herramientas del ecosistema .NET.

---

## 🧠 Contenidos

A lo largo de los ejercicios se trabajan temas como:

- Sintaxis básica de C#
- Tipos primitivos y estructuras
- Clases, métodos y propiedades
- Encapsulamiento
- Control de flujo
- Colecciones
- LINQ
- Manejo de errores
- Buenas prácticas y estilo idiomático en C#
- Testing con `dotnet test`

---

## 📁 Estructura del repositorio

Cada ejercicio se encuentra en su propia carpeta, siguiendo la estructura generada por Exercism:
```
exercism/
└── csharp/
    ├── need-for-speed/
    ├── birds-watching/
    └── ...
```

Cada carpeta incluye:
- Código fuente en C#
- Tests provistos por Exercism
- Archivo de proyecto (`.csproj`) cuando corresponde

---

## ▶️ Cómo ejecutar los ejercicios

### Requisitos
- .NET SDK (recomendado .NET 8 o superior)
- CLI de Exercism (opcional, para descargar/subir ejercicios)

### Ejecutar tests

Desde la carpeta del ejercicio:

```bash
dotnet test
```
